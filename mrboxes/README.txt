ROBOT PLAYGROUND - SELF-HOSTED WEBSITE

Upload all files in this folder to a folder on your website, for example /robot/.
Open https://your-domain.example/robot/ in a desktop browser.
Keep index.html, the JavaScript files and game-robot.glb together.

This is a static website. No Node.js, build process, database, API key or
server-side application is required on your hosting service.
All required libraries and the textured robot model are included locally.

Serve .js files as JavaScript (text/javascript or application/javascript).
Serve .glb files as model/gltf-binary or application/octet-stream.
Use the website address to run it; opening index.html directly from your disk
may be blocked by browser restrictions on module and model loading.

CONTROLS
W: walk forward. A/D: turn while held.
W+A or W+D: walk and turn together.
Release controls to settle to rest.
Drag horizontally with the left mouse button to orbit the character.
The starting camera faces the front of the robot.

Keep THREE-LICENSE.txt with the included Three.js library.
